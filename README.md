# 🐾 NovaPet - 你的網頁專屬 AI 虛擬寵物「小雞毛」

NovaPet 是一款基於 Chrome 擴充功能架構開發的趣味工具。它會在你的瀏覽器視窗中召喚出一隻名為「小雞毛」的可愛狗狗，這隻狗狗不僅會在網頁上隨機漫步，還能透過 OpenAI GPT 模型與你進行即時、幽默的對話。

---

## 🌟 功能亮點

* **AI 智能對話**：串接 OpenAI API (GPT-3.5-Turbo)，根據設定的性格生成專屬對話。
* **動態行為模擬**：狗狗會以平滑的動畫在網頁內隨機移動，並定期彈出對話框與你互動。
* **直覺式拖曳**：使用者可以隨時用滑鼠按住狗狗，將其即時拖曳至螢幕任何位置。
* **互動狗屋系統**：
    * **回家休息**：將狗狗拖曳至左下角的「狗屋」範圍，狗狗會自動進入屋內休息並更換圖片狀態。
    * **召喚出門**：點擊網頁右上角的 **"Let Dog Out"** 按鈕即可再次讓狗狗出來玩耍。

---

## 🛠️ 使用技術與語法

本專案結合了前端網頁技術與人工智慧 API 調用：

* **開發規範**：使用 **Chrome Extension Manifest V3**，確保安全與資源管理。
* **核心語法**：使用 **原生 JavaScript (Vanilla JS)** 處理動態 DOM 建立、非同步 API 請求及碰撞偵測。
* **人工智慧**：串接 **OpenAI API**，透過 `fetch` 獲取 AI 生成內容。
* **樣式與動畫**：利用 **CSS3 Transition** 實現狗狗移動與對話框顯現的平滑效果。
* **資源管理**：透過 `manifest.json` 管理外部圖片（GIF 與 PNG）的存取權限。

## 🚀 如何下載與啟用

如果你想要在自己的瀏覽器中使用 NovaPet，請按照以下步驟操作：

### 1. 準備程式碼檔案
確保你的電腦中包含以下關鍵檔案：
* `manifest.json` (擴充功能設定檔)
* `content.js` (核心邏輯腳本)
* `dog.gif`、`dogHouse.png`、`dogHouseWithDog.png` (視覺資源圖片)

### 2. 配置 API Key (必要步驟)
為了啟動 AI 對話功能，你需要配置自己的 OpenAI 憑證：
1.  開啟 `content.js` 檔案。
2.  尋找並將以下程式碼中的預留文字替換為你的 **API Key**：
    ```javascript
    // 請替換為你從 OpenAI 官網取得的真實 API KEY
    const OPENAI_API_KEY = "sk-************************************************";
    ```
    > ⚠️ **安全性提醒**：為確保帳號安全，請勿將包含真實 Key 的檔案上傳至公開平台（如 GitHub）。

### 3. 將擴充功能載入 Chrome
1.  開啟 Chrome 瀏覽器，在網址列輸入 `chrome://extensions/` 並進入。
2.  開啟右上角的「**開發者模式 (Developer mode)**」。
3.  點擊左上角的「**載入解壓縮擴充功能 (Load unpacked)**」。
4.  在檔案瀏覽視窗中，選擇包含上述檔案的整個專案資料夾。

### 4. 開始互動與使用
* **召喚狗狗**：載入成功後，重新整理任何網頁，「小雞毛」就會跳出來在螢幕上漫步。
* **與牠對話**：狗狗移動後會自動彈出 AI 生成的可愛對話框。
* **自由拖曳**：你可以用滑鼠左鍵按住狗狗，將牠帶到你喜歡的位置。
* **送牠回家**：將狗狗拖曳到左下角的「狗屋」圖示上，狗狗會進入屋內並顯示「我回家囉！」。
* **再次出來**：點擊網頁右上角的 "**Let Dog Out**" 按鈕即可。
